About Film Collection

Welcome to the Film Collection application! This project was developed as part of the Angular course at RS School. It's a modern, reactive web application designed for movie enthusiasts to explore and manage their favorite films.

Key Features:

  • 🎬 Film Catalog — Browse a collection of top-rated movies.
  • 🔍 Instant Search — Find your favorite films in real-time.
  • ⚡ Modern Tech — Built using **Angular Signals** for lightning-fast performance.
  • 📱 Responsive Design — Enjoy the experience on any device.
